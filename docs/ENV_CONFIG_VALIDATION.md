# .env, GGUF 및 입력 해상도 검증 (2026-10-05)

Windows / RTX 3070 Ti 8GB / RAM 32GB / Python 3.12 / PyTorch 2.8.0+cu128에서 확인했습니다. 다른 물리 PC에서 실제 설치·생성을 검증한 것은 아닙니다.

- 자동 테스트 17개 통과: 잘못된 설정 중단, OS 변수 우선순위, 정점 범위 고정, VRAM 제한, 1536·2048 리사이징/원본 보존, NAF 비정수 타일 계산의 전체 연산 기준 비교 등.
- 실제 ComfyUI 노드 규격으로 3 모델 프로필 × 2 입력 해상도 × 싱글/멀티뷰 = 12개 워크플로 연결 검사 통과. 이는 12개 전체 생성 테스트를 의미하지 않습니다.
- Trellis 2 GGUF Q4_K_M: 싱글뷰 입력 1536 / 형상 요청 1536 → 실제 1024 / 투영 텍스처 2048. 추론 및 메시·UV·내장 텍스처 검증 통과.
- Pixal3D GGUF Q4_K_M: 싱글뷰 입력 2048 / 형상 요청 2048 → 실제 1024 / 투영 텍스처 2048. 전체 드래그 생성과 후처리·입력 옆 GLB 복사 통과. 최종 기하 정점 1474개. 원본 표면 대체 경로를 사용했으며 경계 61, 비정상 연결 123개가 남아 `completed_review_required`입니다. 수밀·리깅 준비 완료 결과로 간주하지 않습니다.

GGUF 흐름은 공식 GGUF 연산 의존성을 포함하고 메시 저장에는 기존 ComfyUI 내보내기 노드를 사용합니다. Pixal3D NAF는 Windows용 PyTorch 경로 및 비정수 타일 크기 보정을 사용합니다. 가중치는 SHA256 고정 다운로드이며 소스·가중치를 Git에 넣지 않습니다.

8GB에서 1536·2048 **입력 준비**는 확인했습니다. 이 테스트의 **형상 생성은 1024**입니다. 아래 추가 테스트를 제외한 다른 모델·다중 시점·2048 형상 추론은 별도 검증이 필요합니다. 구성 복잡도에 따라 정점 감소에서 형상 검사가 실패하거나 보수 검토가 필요한 결과가 나올 수 있습니다.

Trellis 2 실제 생성 결과의 추가 후처리에서는 환경 변수 `SINGLE_VERTEX_MIN=1500`, `SINGLE_VERTEX_MAX=2000`을 적용해 최종 1985정점으로 완료했습니다. 작업 보고서의 정점 범위도 `[1500, 2000]`이며 기존 기본 범위에 고정되지 않음을 확인했습니다. 상태: `completed_review_required`.

## 추가: 8GB에서 실제 1536 형상 생성

기본 VRAM 정책은 유지하고 테스트 프로세스에만 제한을 해제했습니다. Trellis 2 GGUF Q4_K_M / 싱글뷰 / 예제 front.png / 형상 1536 / 투영 텍스처 2048로 실제 생성·저장·후처리를 완료했습니다. 노드 내부의 토큰 제한에 의한 해상도 하향 로그가 없고, 1536 디코딩은 432개 타일로 실행됐습니다. ComfyUI 추론/내보내기 실행 시간은 190.60초이며 후처리 시간은 별도입니다.

2초 간격 nvidia-smi 표본에서 GPU 메모리 최대 4438MiB(4.33GiB)를 기록했습니다. 짧은 순간의 최대값을 보장하는 측정은 아닙니다. 최종 정점 1260개, 상태 completed_review_required이며 연결·구멍 보수 검토가 필요합니다. 배치가 시작한 ComfyUI는 완료 후 자동 종료됐습니다.

이 이미지와 모델에서는 8GB로 실제 1536 형상 생성이 가능했습니다. 다른 이미지·멀티뷰·Pixal3D 1536까지 검증한 것은 아닙니다. 이번 요청은 시도 테스트이므로 일반 실행의 자동 1024 제한과 기존 .env는 변경하지 않았습니다.
