# 설치 및 실행 검증

검증 장비: Windows x64 / RTX 3070 Ti 8GB / NVIDIA 드라이버 616.64 / RAM 약 32GB.

다른 물리 PC에서 검증한 것은 아닙니다. 같은 PC에서 기존 설치 재사용과 별도 공백·한글 경로의 새 Python·Blender 환경을 분리해 검사했습니다. 새 환경은 기존 Python 패키지를 연결하지 않았으며, 대용량 모델 파일만 SHA256 확인 후 재사용했습니다.

| 검사 | 내용 |
|---|---|
| 기존 설치 재사용 | 정상 Python·CUDA·모델 재사용, 기존 시스템 환경 보존 |
| 새 환경 | Python 3.12.10 및 고정 패키지 전체 설치, pip check |
| CUDA | 실제 matmul 및 새 캐시에서 Triton 커널 컴파일 |
| 다운로드 | 22개 고정 모델 URL 접근·크기 확인, 로컬 파일 SHA256 검사 |
| 다운로드 복구 | 중단 파일 Range 재개, 손상 파일 교체, 정상 파일 다운로드 생략 |
| 압축 해제 | 상위 경로 침범하는 ZIP 항목 차단 |
| Blender | 전용 설정 폴더, Kimodo/Mixamo Rig 로드, 컨트롤 리그 생성 |
| 모션 | 실제 Kimodo.cpp SOMA30 추론, Blender 리타게팅, 발가락 보정 |
| 재실행 | setup 재실행 시 정상 항목 생략, 모델 재다운로드 없음 |
| 한글 경로 | 내장 Python 경로 설정과 Windows CLI UTF-8 manifest 보정 |

기존 환경 경로의 실제 3D 생성은 1024 형상·2048 투영 텍스처·메시 정리·리토폴로지까지 완료했습니다. 샘플의 최종 Blender 메시 정점은 1252개이며, 결과 GLB는 examples/generated_3d.glb입니다. 별도 리깅 샘플에서 실제 60프레임 Kimodo 모션을 생성하고 적용했습니다.

새 Python·Blender 환경과 공백·한글 경로에서도 전체 3D 생성 및 실제 Kimodo.cpp 60프레임 생성 → Blender 적용이 통과했습니다. [fresh-generation-report.json](fresh-generation-report.json)에 범위를 기록했습니다. staged Git tree를 ZIP으로 추출한 패키지에서도 필수 런타임 해시와 설치 도구 테스트가 통과했습니다.

전체 테스트는 `run_generation_test.bat`, 설치 점검은 `verify.bat`으로 반복할 수 있습니다. 로그와 상세 결과는 각 설치의 `.state/`와 `runtime/ComfyUI_3D_1024/results/`에 저장됩니다.

**생성 성공과 메시 완성도는 다릅니다.** 샘플 리토폴로지에는 작은 경계 개구부가 남아 있어 수동 보수 검토가 필요합니다. 피부·손가락·옷과 관절의 변형 품질까지 자동 승인하지 않습니다. 멀티뷰는 정확한 front/back/left/right 파일명 검사를 사용하며, 입력과 사양에 따라 처리 시간이 달라집니다.

## 2026-10-05 방패 입력 후처리 복구

실제 드래그 입력에서 Instant Meshes 결과의 가시 표면 거리 P95가 원본 대각선의 2.692%로, 기존 허용치 1.5%를 넘었습니다. 형상 생성과 텍스처 투영은 완료됐지만 재베이킹 전에 중단됐습니다.

형상 검사 실패에 원본 기반 표면 감소를 재시도하도록 추가했습니다. 기존 연결 결함으로 보수가 필요한 이 입력은 보수한 표면을 감소시킨 후 Blender 메시 검증으로 중복 면 1개를 제거해 1461정점, 경계 에지 3, 세 면 이상 연결 에지 0, 퇴화 면 0으로 완료했습니다. 남은 경계는 수동 검토가 필요합니다. 가시 표면 P95는 0.428%이며 2048 색상·금속/거칠기 텍스처 재베이킹과 GLB 내장 검사가 통과했습니다. 원본 파일 SHA256도 유지됐습니다. 이 방식은 삼각형 위주이며 관절용 엣지 흐름을 보장하지 않습니다.

회귀 테스트는 형상 거절과 Instant Meshes 120초 타임아웃에서 검증을 유지하는 대체 방식을 실행하는지, 이전 거절 파일이 남아 있어도 다른 Blender 오류를 숨기지 않는지 검사합니다. 설치 테스트 포함 6개 테스트가 통과했습니다.

## 2026-10-05 대검 입력 정점 감소 복구

한글 파일명의 대검 입력은 이미지 읽기·3D 생성·텍스처 매핑까지 완료됐습니다. Instant Meshes 결과는 형상 검사에서 거절됐고, Voxel 보수 표면의 Collapse 감소는 비율을 낮춰도 1658정점에 머물러 싱글뷰 상한 1500을 넘었습니다. 한글 경로 인코딩 오류가 아닙니다.

평면 정리·중복 면 검증 후 재감소와 정리된 원본 표면으로의 추가 재시도를 적용했습니다. 동일한 결과의 후처리만 실행해 1459정점, 가시 표면 거리 P95 0.115%, 2048 색상·금속/거칠기 맵을 내장한 GLB를 생성하고 한글 입력 파일 옆으로 복사했습니다. 경계 에지 19개, 세 면 이상 연결 에지 36개가 남아 수동 보수 검토가 필요하며, 메시가 완전히 정상이라는 판정은 아닙니다. 최종 모델을 설정된 Blender에서 열었습니다.

설치·미리보기·후처리 회귀 테스트 10개가 통과했습니다. 추가 테스트는 Voxel 표면의 정점 예산 실패 시 정리된 원본 표면을 재시도하는지, 오류 메시지에 실제 Blender 예외를 표시하는지 검사합니다.

## 2026-10-05 토끼 입력 하한 오류 복구

`귀요미_토끼3.png`의 Instant Meshes 결과는 정리 후 879정점으로 감소해 하한 1000에 못 미쳤습니다. 기존 코드는 형상 검사 전에 하한 오류로 중단했고, Voxel 보수가 없는 입력의 정점 오류에서는 대체 경로도 실행하지 않았습니다.

하한을 형상 검사 뒤에 처리하고, Voxel 보수 여부와 무관하게 정점 예산 실패도 대체 경로로 연결했습니다. 수정 후 해당 Instant Meshes 결과의 가시 표면 거리 P95 5.289%를 거절하고 정리된 원본 표면으로 재베이킹해 1482정점, 경계·비정상 연결·퇴화 면 각각 0개, 가시 표면 거리 P95 0.00431%로 완료했습니다. 최종 GLB의 2048 텍스처 내장·유한 좌표·삼각형 인덱스·면적 검사를 통과했고 입력 이미지 옆으로 복사했습니다.

설치·미리보기·후처리 테스트 11개가 통과했습니다. 추가 실제 Blender 테스트 `tests/blender_vertex_budget.py`는 큐브를 싱글뷰 1000·멀티뷰 2000정점으로 보충하고 표면·부피·정상 연결이 유지되는지 검사합니다. 정점 보충은 형상 검사에 통과한 표면에만 적용합니다. 평면 정리는 Voxel 보수 표면에만 적용해, 일반 원본 표면에서 이 단계가 오래 걸리는 문제도 피했습니다.
